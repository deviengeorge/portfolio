[ALReserve](https://alreserve.com) is a membership-based luxury accommodation booking platform designed for Gulf Cooperation Council (GCC) travelers seeking premium stays in the UK, USA, and Europe.

## The Challenge

GCC travelers seeking luxury accommodations need a platform that understands their preferences — Arabic-first interface, curated high-end properties, and a membership model that provides exclusive rates and personalized service.

## Solution

Building a full-stack platform with a TypeScript monorepo architecture, integrating multiple third-party booking APIs for comprehensive property coverage while maintaining a premium user experience.

### Key Features

- **Multi-provider Hotel Search** — HyperGuest, Hotelbeds, RateHawk, and Interhome behind one normalized provider layer, with Meilisearch-powered search and nightly booking reconciliation
- **RTL-first Internationalization** — Arabic/English support using react-i18next and Tailwind logical properties
- **Membership System** — Tiered access with exclusive rates and benefits
- **Reservation Management** — End-to-end booking flow with confirmation and modification support
- **Payments & Verification** — Revolut payments and identity verification before booking
- **Notifications & Ops Alerts** — In-app and email notifications for booking and membership events (respecting member preferences), plus a Telegram bot that alerts the ops team when a booking needs a human
- **Background Job Processing** — pg-boss for async tasks like email notifications and rate syncing

## Technical Architecture

- **Frontend:** React 19 with TypeScript, Tailwind CSS, RTL-first design
- **Backend:** AdonisJS 7 REST API on Node (migrated from an earlier Hono/Bun prototype), Lucid ORM, pg-boss jobs
- **Data:** PostgreSQL, Meilisearch for search; own password/session auth, with Supabase kept for storage
- **Caching:** Fail-open Redis JSON caches: if Redis is down, reads become misses and requests still resolve from the source. TTLs follow each data type: 60 s per-hotel live availability (protects supplier rate limits), 10 min search availability, 24 h nearby places, exchange rates with a week-long stale fallback
- **Third-party services:** Revolut (payments and webhooks), Didit (identity verification), Google Places, Geoapify, GeoNames, OpenStreetMap Overpass, Mapbox, OpenRouter (LLM), SMTP mail, Sentry
- **Infrastructure:** Self-hosted on Hetzner: three servers (app, data, auth) on a private network, deployed with Coolify and Traefik with automatic TLS
- **CI/CD & Ops:** Woodpecker CI, Prometheus and Grafana monitoring, firewall rules, image CDN, scripted database backups with restore tooling
- **Internal Tools:** Go terminal admin app (Bubble Tea) for bookings, isolated per-provider test environments, Playwright demo-video recorder
- **Quality:** Biome, Japa and bun:test suites, Playwright E2E, pre-commit checks with lefthook
- **Architecture:** TypeScript monorepo with shared types and utilities
